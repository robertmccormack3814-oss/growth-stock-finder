# Growth Stock Finder

A quality-growth screening engine for ASX ordinary equities. It is designed to find companies where growth, business quality, financial strength, market confirmation and valuation line up at the same time.

## Signal model

The 100-point score is deliberately multi-factor:

- Growth — 30 points: current revenue growth, current earnings growth, multi-year revenue CAGR and EPS CAGR.
- Quality — 25 points: ROE, approximate ROIC, ROA, gross margin, operating margin and free-cash-flow margin.
- Balance sheet — 15 points: current ratio, debt/equity, net debt/EBITDA and interest coverage.
- Momentum — 20 points: 50/200-day trend, 6-month return, 12-month relative strength versus the ASX 200, proximity to the 52-week high and volume confirmation.
- Valuation — 10 points: PEG, P/E relative to growth and FCF yield.

A separate 0–100 risk score considers volatility, drawdown, beta, leverage, growth-adjusted valuation and market-cap risk. Lower is better.

Default classifications:

- PASS: score >= 78, risk <= 65, above 200-day moving average, positive cash/profit gate and a minimum growth gate.
- WATCH: score >= 65 but not all PASS requirements are satisfied.
- NO SIGNAL: below the watch threshold.

A PASS is a research signal, not financial advice or an instruction to buy.

## Email alerts

Add these repository secrets under **Settings → Secrets and variables → Actions**:

- `SMTP_USERNAME` — Gmail address used to send and receive the alert.
- `SMTP_APP_PASSWORD` — Google app password for that Gmail account.

The scanner emails only when a stock newly changes into PASS. It does not repeatedly email the same stock while it remains a PASS.

## First run

Open **Actions → Growth Stock Finder → Run workflow**. The first run builds the ASX universe and scans the first rotating batch. Later scheduled runs continue from the saved cursor.

For a larger manual batch, enter a larger `batch_size` in Run workflow. The default is 120 because financial-statement requests are much heavier than simple price requests.

## Dashboard

The repository contains a mobile-friendly `index.html`. Enable GitHub Pages using the `main` branch and root folder to publish the dashboard. It reads `data/ranked.json` generated by the scanner.

## Configuration

Edit `config.json` to change the PASS/WATCH scores, liquidity/market-cap limits, risk ceiling, batch size or factor weights.
